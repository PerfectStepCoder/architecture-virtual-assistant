# Architecture-virtual-assistant

# Структура:
- assistent (ассистент-модель)
- web (веб-интерфейс для отправки сообщений к модели)

# Развёртывание веб-приложения
- npm install
- npm run build
- npm run start

## Тренирровка модели
> rasa train

## Запуск модели в режиме DEBUG
> rasa run -vv --cors "*"  (я отключил CORS так как запускаю модель на своем удаленном сервере, а фронт запускаю локально у себя на ПК)

## Запуск фронта
> npm run start

В файле фронта src/components/Basic.js изменил URL: http://135.181.26.222:5005/webhooks/rest/webhook

## Диалоги
На главной форме ввожу вопросы, получаю привествие, но диалог короткий, только предложение от агента о рассказе об архитектуре.
Видимо нужно рассширять сценарии.

Для подключения современных LLM я планирую использовать: LangChain

LangChain будет лучше, если:
- Вы хотите мощный бот с естественным пониманием языка и генерацией ответов.
- Ваш проект требует интеграции с внешними данными (например, база знаний, API).
- Вы готовы писать кастомный код (например, FastAPI для бэкенда).
- Вы можете использовать облачные LLM или у вас есть оборудование для локальных моделей.
